# Live-run findings: `lab/deploy`

Every problem met while running `lab/lab.sh` on a single-node k3s sandbox (Ubuntu 24.04, 32 vCPU, 31 GiB, QEMU CPU without AVX), 2026-09-26 and 27, and what was done about it. "Run N" is a live attempt; "clean run N" started from an empty cluster. Clean run 4 passed `up` and `test`. The summary and the open items are in `lab/HANDOFF.md`.
